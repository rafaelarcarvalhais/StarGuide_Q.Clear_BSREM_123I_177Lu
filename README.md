# StarGuide_Q.Clear_BSREM_123I_177Lu
This repository contains the original data used in the manuscript "Optimisation of Q.Clear (BSREM) Reconstruction Parameters for ¹²³I and ¹⁷⁷Lu Imaging with a 360° CZT Detector" study. The data is organised by radionuclide. 

## Contents
- VOI statistical data obtained from the quantitative analysis MIM Software workflow developed within the context of this manuscript (the Workflow description can be found in Section S1 of the Supplementary Material). 
- Recovery Coefficients (RC), Background Variability (BV), Signal-to-Noise Ratio (SNR) and Contrast Recovery Coefficients for all reconstruction protocols presented in the manuscript. 
- Calibration Factors (CF) for all reconstruction protocols presented in the manuscript (the calibration strategy can be found in Section S1 of the Supplementary Material).
- Python Scripts: RC, BV, SNR and CRC calculation and figure generation; EANM fitting;

## Raw CT and SPECT data are not publicly available in this repository. They are available from the corresponding authors upon reasonable request.

## Software: Python (version 3.14); MIM Software (version 7.3.4) and SmartConsole (version X).
