## The following contents are available on this folder:##  
  - Data_BV_Calculation: Background VOIs' statistical data needed for BV calculation for each of the VOI sets considered (_1: 100 mL; _2: 50 mL; _3: 26.5 mL; _4: 2.6 mL; _5: 0.5 mL).
  - Data_RC/Data_BV/Data_SNR/Data_CRC: RC, BV, SNR and CRC values determined for each reconstruction protocol (RR1-RR20: StarGuide/Q.Clear; SS1: Symbia/OSEM).
  - Slices: Representative slices of the NEMA phantom for each reconstruction protocol.
  - VOI_NEMA: VOIs' statistical data obtained by application of the NEMA phantom quantitative workflow discribed in the Supplementary Material of the manuscript.
