## The following contents are available in this folder: ##
  - Data_BV_Calculation: Statistical data for the background VOIs required for BV calculation for each of the VOI sets considered (_1: 100 mL; _2: 50 mL; _3: 26.5 mL; _4: 2.6 mL; _5: 0.5 mL).
  -  Data_RC / Data_BV / Data_SNR / Data_CRC: RC, BV, SNR, and CRC values obtained for each reconstruction protocol (labels follow the nomenclature presented in Table 3 of the manuscript).
  -   Slices: Representative slices of the NEMA phantom for each reconstruction protocol.
  -   VOI_NEMA: VOI statistical data obtained using the NEMA phantom quantitative workflow described in Section S1 of the Supplementary Material of the manuscript.
